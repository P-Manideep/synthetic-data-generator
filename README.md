# 🚀 Synthetic Data Generator

A web-based synthetic data generation platform that creates realistic datasets for testing Machine Learning models, dashboards, analytics systems, and data pipelines.

🔗 **Live App:**  
https://synthetic-data-generator-6utgy9n5mkwfn8pznpqcaq.streamlit.app/

---

## 📌 Overview

This project simulates real-world business datasets using statistical distributions, domain rules, and configurable parameters.

It helps developers, data scientists, and testers generate production-like datasets without exposing sensitive data.

---

## ✨ Features

- 🎯 4 Pre-built Business Scenarios  
- 📊 Realistic Statistical Data  
- 🌐 Interactive Web UI (Streamlit)  
- ⚡ Instant Dataset Generation  
- 📁 CSV Download Support  
- 🔁 Scalable Record Generation
